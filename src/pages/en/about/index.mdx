Hello, my name is Christian Schilling.
I am specialized in frontend and design system architecture.
My focus is on developing scalable, performant and accessible web applications with modern technologies like React, Astro, Web-Components and TypeScript.

## My Mission

I help companies improve their digital products by developing design systems and frontend architectures that are easy to use for both developers and designers.
My goal is to optimize the user experience while simplifying the development processes.

## My Toolset

I work with a variety of tools and technologies, including:

- **Frontend-Frameworks:** React, Astro, Vue
- **Design-Systeme:** Storybook, Figma, Web-Awesome
- **Programmiersprachen:** TypeScript, JavaScript, HTML, CSS
- **Testing:** Jest, ViTest, React Testing Library, Playwright
